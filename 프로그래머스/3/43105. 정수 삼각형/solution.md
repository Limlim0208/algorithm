# 개념
## DP (다이나믹 프로그래밍, 동적 계획법)
| 하나의 큰 문제를 여러 개의 작은 문제로 나누어서 그 결과를 저장하여 다시 큰 문제를 해결할 때 사용

## DP 사용 조건
DP가 적용되기 위해서는 2가지 조건을 만족해야 한다.

1. Overlapping Subproblems(겹치는 부분 문제)
      - 동일한 작은 문제들이 반복하여 나타나는 경우에 사용이 가능하다.
2) Optimal Substructure(최적 부분 구조)
    - 부분 문제의 최적 결과 값을 사용해 전체 문제의 최적 결과를 낼 수 있는 경우

## DP 사용하기

1. DP로 풀 수 있는 문제인지 확인한다.
2. 문제의 변수 파악
3. 변수 간 관계식 만들기(점화식)
4. 메모하기(memoization or tabulation)
5. 기저 상태(가장 작은 문제의 상태) 파악하기
6. 구현하기
  1. Bottom-Up (Tabulation 방식) - 반복문 사용
     - 아래에서 부터 계산을 수행 하고 누적시켜서 전체 큰 문제를 해결하는 방식
     - dp[0]부터 시작하여 반복문을 통해 점화식으로 결과를 내서 dp[n]까지 그 값을 전이시켜 재활용
  2. Top-Down (Memoization 방식) - 재귀 사용
       - dp[n]의 값을 찾기 위해 위에서 부터 바로 호출을 시작하여 dp[0]의 상태까지 내려간 다음 해당 결과 값을 재귀를 통해 전이시켜 재활용하는 방식

맨 아래 줄은 그대로 두고, 그 바로 위 줄의 각 숫자에 대해 "자기 밑의 두 칸(왼쪽 아래, 오른쪽 아래) 중 더 큰 값"을 더해서 그 자리값을 갱신. 이렇게 한 줄 한 줄 위로 올라가면서 triangle 자체를 덮어쓰면, 맨 꼭대기(`triangle[0][0]`)에 도착했을 때 그 값이 바로 answer이 됨.

즉 이중 for 문을 통해 `triangle[i][j] += max(triangle[i+1][j], triangle[i+1][j+1])`를 아래 줄부터 위 줄로 반복
